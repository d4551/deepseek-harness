# Agent Note: 变异存活者要么被测试杀死，要么被删除

Status: implemented

[English](2026-08-30-mutation-survivor-repair.md) | 中文

## 问题

工具层的变异门记录为 818 个变异体中 96.58 分、28 个存活者，而 `break` 停在 96.5——最后一个诚实测得的下限——因为那个分数无法复现。低于记录分数的阈值会让介于两者之间的每个存活者落地，而运行仍然显示绿色。存活者分为两类：从未到达被变异分支的断言，以及任何输入都无法将其与周边代码区分开的守卫。

## 决策

每个存活者要么被一个到达被变异分支的测试杀死，要么在它所变异的守卫与旁边的逻辑冗余时被删除。[变异测试决策](2026-06-11-mutation-testing.zh.md)拥有该门的设计——带解释存活者的记录分数，绝不使用排除清单；本笔记记录执行它的这一轮。

- **atomic-write 直接钉住 mkdir 调用。** mock 现在记录每一次 `mkdir` 调用，一个测试断言每个 `dirMode` 用例传入的精确选项对象：未请求目录模式时是 `{ recursive: true }`，请求时是 `{ recursive: true, mode }`。多级 `dirMode` 测试创建两个缺失层级并断言两者都带上所请求的模式，因此从任一层级丢弃模式的变异体都会失败。
- **home-paths 对整条祖先链——包括根——回答 ENOENT。** 被模拟的 `realpath` 拒绝路径的每一段，于是遍历到达它的 `parent === current` 守卫并重新抛出，而不是无限下探。守卫的覆盖率忽略注释随覆盖它的测试一起移除。
- **冗余守卫被删除，而不是加注。** `trimTrailingPartialUtf8` 的三个提前返回（空缓冲、越界遍历停止、零长序列）全部折叠进最终的长度比较：越界字节读作 `undefined`，`undefined & 0xc0` 为 0，遍历在 −1 处退出，比较原样返回输入。`createLaunchEnvironmentSnapshot` 无条件存储每层的 `path`，读取侧保留省略 undefined 的归一化，因此写入时的三元表达式和它所喂养的可选链不再有可观察的职责。
- **阈值跟随实测分数。** 新一轮实测为 764 个变异体中 99.08 分（757 个被检出：750 杀死、7 超时；7 存活、0 无覆盖）。单个变异体占 0.131%，因此 `break` 定在 98.9：一个新存活者仍能通过，第二个则使运行失败。
- **剩余的七个存活者各自在上下文中等价。** 完整的等价论证记录在本笔记中；[stryker.config.mjs](../../../../stryker.config.mjs) 在阈值旁点名它们：一个锁竞争 catch 臂——其唯一调用点只读真值，清空的 catch 返回 `undefined`，与它替换的 `false` 同为假值——一个额外迭代只切出空区间的循环边界、一个两个调用点对称折叠的大小写折叠（分歧仅在契约未作规定的非 ASCII Windows 名称对上可达，两种折叠在那里都不匹配原生表）、一个其代码块无论如何都会被后续正则提取的正则替换、一个缺失块提前返回其后续匹配返回同一 `undefined` 的分支、一个越界遍历退出，以及一个续字节遍历不可能停在其中的首字节。

## 已考虑的替代方案

**不动存活者、直接抬高阈值。** 否决：把存活者平均掉正是棘轮所禁止的，而 break 与记录分数之间的差距就是该门会放过的回归数量。

**在 Stryker 配置中排除等价变异体。** 否决：排除清单是一个随时会被伸手去用的诱惑——每当某个变异体只是碍事时——并且它会把同一行上未来不等价的变异体一起藏起来。[变异测试决策](2026-06-11-mutation-testing.zh.md)已因同样的理由否决过逐行注释。

**保留冗余守卫并解释它们的变异体。** 否决：任何输入都无法到达的守卫是死代码，其变异体永远无法被杀死；删除它同时移除欠账与存活者。

## 后果

工具层实测 99.08、`break` 98.9，七个存活者的等价论证记录在本笔记中。第二个新存活者会使运行失败。home-paths 的根守卫由测试覆盖而非覆盖率忽略注释，因此该行的覆盖是被断言的，而不是被假设的。
